## 규약 (양쪽 세션 공통 — 검수장 `mailbox/MAILBOX.md` 규약과 동일 원리)

1. **위치 고정**: `클로드-프로그램만들기\solver\mailbox\MAILBOX.md` — solver/ 가 자체 git 저장소라 **git 이력이 수신 증빙**이다.
2. **ID 접두는 `S-`** (검수장↔본체 채널의 `M-`과 구분). 행을 쓰기 전에 마지막 ID를 다시 봐라.
3. **보내는 쪽**: 표에 행 추가 + 상태 `🔴 미확인`. 본문은 여기 쓰지 말고 **파일 포인터**만
   (검수장 발신 → `홀덤검수/reports/…` · 솔버 발신 → `클로드-프로그램만들기/…`). 🔴 행에 개행 금지 · 파이프 7개(6열) 확인.
4. **받는 쪽**: 세션 시작 때 이 파일에서 `🔴` 검색 → 읽으면 `🟡 확인(MM-DD)`, 끝나면 `✅ 완료(MM-DD·커밋해시)`로 **직접** 갱신.
   **오래된 것부터** 한 건씩 · 마지막 것만 보지 마라.
5. **상태 열은 받는 쪽만, 나머지 열은 보낸 쪽만 수정. 행 삭제 금지** — 완료 행은 월 단위로 하단 아카이브 절로.
6. **커밋**: 상태 변경 즉시 커밋(접두 `mailbox:`). 검수장도 이 저장소에 **mailbox/ 한정** 커밋 가능 — 다른 파일 금지.
7. 🔴 **경계 조건 둘** (세 세션 정합 — 검수장 계획 §0-B):
   ⓐ **기발신 통지(④⑦⑧⑩+①·③ 하드코딩 권고)는 검수장↔본체 채널(M-)로 완결**한다 — 이 채널로 재발신 금지. **신규 발견분부터 직통.**
   ⓑ 앱 문구가 **랜딩·글의 근거인 자리**의 발견은 검수장이 본체 우편함에도 참조 한 줄을 남긴다.
